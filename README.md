# All 12 clinic systems on one live dashboard — working preview

**Live preview:** https://clinic-preview.previewlab.app/  · toggle **EN · RU** in the header — the whole preview is bilingual.

A working preview of a unified operations dashboard for a multi-branch clinic: all 12 systems on one board, on honest demo data. One integration is real — a **live Gmail bridge**: send a test email and watch it land on the board in seconds.

## 60-second route
1. Open the live preview above. The KPI board runs on honest demo data — every widget is labeled.
2. In the mail widget, click **"Reveal address"** and send any test email to it from your own mailbox.
3. Watch it land on the dashboard within seconds — that is the live Gmail integration, not a mock-up.
4. Scroll to the hub map: all 12 systems of a multi-branch clinic, grouped into 4 domains, each honestly marked.
5. Toggle **EN · RU** in the header — the whole preview is bilingual.

## What the preview covers — and what a full build adds
- **Covers:** the dashboard shell, all 12 systems visible on one board, one real integration (live Gmail bridge).
- **Full build adds:** live connections to each system — practice management, telephony, CRM, payments, accounting — auto-refresh, role-based access, and your own data instead of demo data.

The gap is the project; the preview is the proof of approach.

> Method: from brief to a working preview in hours. This demo runs on honest, labeled demo data — no real patient or client information.
